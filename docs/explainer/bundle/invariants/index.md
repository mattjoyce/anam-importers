# Invariants

* [A batch is at most 49 envelopes](a-batch-is-at-most-49.md) - No submission carries more than 49 envelopes, and a larger one is cut, because Anam refuses it and the number decides which events share a commit.
* [A Definition version Anam holds is never overwritten](a-held-definition-version-is-never-overwritten.md) - ensure_published registers a missing Definition and leaves a held one alone, and stops the run when the held body differs from the importer's, so a version means one thing.
* [A geocoder that is down never stops a stay](a-down-geocoder-never-stops-a-stay.md) - The geocoder returns nothing on any network or parse failure, so a stay is sent without a place and the place backfills on a later run.
* [A plugin always answers with exactly one response](a-plugin-always-answers-once.md) - Whatever a handler does, stdout holds one JSON object, with failures carrying a retry flag, because a traceback tells the supervisor nothing it can act on.
* [A run claims to be a snapshot only when it read everything](a-snapshot-claims-everything.md) - An importer that skipped a file, a line, a result or an oversized payload sends its batches without a snapshot label, so Anam cannot call the unread facets absent.
* [An absent alert retracts nothing](an-absent-alert-retracts-nothing.md) - When a complete resend leaves facets absent, anam_submit raises an alert with the counts and some ids, and retraction stays with an operator running a separate command.
* [An envelope names no source and no source reference](an-envelope-names-no-source.md) - The token names the source and Anam composes identity from the Definition, so an importer's envelope carries a type, a version, a payload and at most an asserted person.
* [An importer reads its source and does not write to it](a-source-is-read-never-written.md) - SQLite sources open read-only, files and folders are read and not modified, and the only files an importer writes are its own cache and geocoder cache.
* [Config is read and checked once, at the start of a command](config-is-read-and-checked-once-at-start.md) - Each command reads its keys through the config helpers into values it passes down, and a bad value fails there naming the key before any source or Anam is touched.
* [Coordinates stay in the payload](coordinates-stay-in-the-payload.md) - The OwnTracks and stays importers put positions only in envelope payloads, and their logs, result lines and event names carry counts, file names and line numbers.
* [Every external call has one total deadline and a size cap](every-call-has-a-deadline.md) - A call to Anam or the Logbook is bounded across connect, headers and body, and an answer over the cap is an error, so a plugin never hangs and never reads without limit.
* [Every payload is validated before anything leaves](validate-before-anything-leaves.md) - An importer runs check on all its envelopes against the Definitions it carries before emitting an event, so a later refusal means the two sides disagree and not that a row was malformed.
* [No redirect is followed with a token](no-redirect-is-followed.md) - A 3xx answer from Anam or from the Logbook is an error, so a bearer token never reaches another host, port or scheme.
* [Only anam_submit holds an Anam token](only-anam-submit-holds-an-anam-token.md) - Importers read no Anam token and call no Anam endpoint, and anam_submit reads exactly the secret its instance names.
* [The repository has one version](the-repo-has-one-version.md) - VERSION, the base package, every plugin manifest and the changelog's newest release all name the same number, and a test fails when one disagrees.
