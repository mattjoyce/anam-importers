# Decisions

* [A blood pressure reading is sent from the newest export that holds it](a-reading-is-sent-from-the-newest-export.md) - Exports overlap and later ones may correct a comment, so poll orders exports by the date in their name and sends each reading once, from its newest holder, and handle leaves readings a newer export holds.
* [A config key for every default, a constant for every invariant](config-keys-for-defaults-constants-for-invariants.md) - A value someone could reasonably choose differently is a snake_case config key with its shipped default, range-checked at start, and a value whose change breaks data or the contract stays a commented constant.
* [A track hour is sent whole every time it changes](an-hour-is-sent-whole.md) - The OwnTracks importer makes one facet per phone per UTC hour holding all its points, and re-sends the whole hour when any point arrives, because the new facet version replaces the last.
* [Fetch and shape are separate commands](fetch-and-shape-are-separate-commands.md) - The Concept2 importer reads the remote API in a fetch command that fills a local cache, and shapes only the cache in handle and poll, so shaping never touches the network.
* [Importers carry the Definitions they emit and publish them on first use](importers-carry-their-definitions.md) - Each importer ships the Definition files for its types and validates against them, and anam_submit registers a missing one, while types Anam already bundles are carried by nobody here.
* [Importers keep no state and resend everything](importers-keep-no-state-and-resend-everything.md) - An importer remembers nothing between runs, so every source gets a poll command that sends all it holds, and Anam's no-op on an unchanged payload makes that safe and a snapshot makes it informative.
* [One submit instance per importer holds the token](one-submit-instance-per-importer-holds-the-token.md) - Importers hold no Anam token. A generic anam_submit plugin posts for all of them, run as one instance per importer so each token is reachable only by the plugin that uses it.
* [Payload ids name what they are](ids-name-what-they-are.md) - The Garmin importer prefixes its ids (garmin:session:, sleep:, steps:, day:) because a facet's identity is the source plus the identity values and does not include the type.
* [Records are read with Go yaml.v3 scalar rules](records-reads-yaml-by-go-rules.md) - The records and documents importers resolve YAML scalars as Go yaml.v3 does, not as YAML 1.1, so the payload text of a number or a date does not change with the reader.
* [Stays are derived, and the track is untouched](stays-are-derived-and-the-track-is-untouched.md) - Naming the places a phone stopped is a separate importer and a separate facet type, so place.track facets keep the raw fixes and a geocoder outage never blocks them.
* [Tests use real components and invented data](tests-use-real-components-and-invented-data.md) - Tests run plugins as subprocesses on real SQLite files and real folders, run against a real anam daemon when ANAM_BIN is set, and use only made-up values.
* [The client trusts only a whole receipt](the-client-trusts-only-a-whole-receipt.md) - A 200 from Anam counts as success only when its body is a complete admission receipt, and anything less is a retryable error that emits no admitted event.
* [The HTTP clients use the standard library](the-http-client-is-the-standard-library.md) - Anam calls and Concept2 calls use http.client with a single deadline and no redirects, and the only third-party imports are jsonschema, pyyaml and two pinned decoders in script headers.
